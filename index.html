Data Notes
BTC candles use Kraken public data for technical calculations. Kalshi crypto contracts use the CF Benchmarks RTI for settlement; Kalshi says the final value for crypto contracts is the average of 60 one-second RTI observations in the final minute. V8.1 adds a rolling order-book depth/imbalance history and interactive candle inspection, trade-flow delta, liquidity stacking/pulls and sweep-aware sniper trigger. REST polling is intentionally throttled. GitHub Pages cannot bypass Kalshi browser CORS, so Kalshi reads use direct public API requests first and a read-only CORS relay fallback when the browser blocks them. This is still an analytical model, not the official Kalshi probability or settlement feed.
